Complete Step-by-Step Guide: Installing WhatsApp AI Agent on Another Android Device (Termux)

This guide walks you through setting up the entire WhatsApp AI Agent standalone on any Android phone using Termux.

📱 Phase 1: Prepare the Android Phone

1. Enable Developer Options & Debugging

  1. Open phone Settings > About Phone.
  2. Tap Build Number 7 times until you see "You are now a developer!".
  3. Go back to Settings > System > Developer Options:
  • Turn ON USB Debugging (if using a cable) OR Wireless Debugging (if using Wi-Fi without a PC).
  • Turn ON Disable Permission Monitoring (if present on your brand: Xiaomi/Oppo/Realme/OnePlus).

2. Install Termux & Termux:API (From F-Droid)

Important Do NOT download Termux from Google Play Store (that version is deprecated and won't update packages).

  1. Download & install Termux from the F-Droid Termux Page: https://f-droid.org/en/packages/com.termux/
  2. Download & install Termux:API from the F-Droid Termux:API Page: https://f-droid.org/en/packages/com.termux.api/

📂 Phase 2: Transfer the Project Files to the Phone

Transfer the project archive whatsapp_ai_agent.zip to the target phone using any method:

  • Via USB cable into the phone's Download folder.
  • Via Quick Share / Nearby Share / Bluetooth.
  • Via Telegram / WhatsApp / Google Drive to your phone.

(The file will typically sit in your phone's /sdcard/Download/ folder).

💻 Phase 3: Install & Configure Inside Termux

Open the Termux app on the phone and run the following steps:

Step 1: Grant Storage Permission

termux-setup-storage

Tap Allow when the Android prompt asks for storage access.

Step 2: Copy & Extract the Package

Copy the zip file from your phone's Download folder into Termux and extract it:

# Copy from phone storage to Termux home
cp /sdcard/Download/whatsapp_ai_agent.zip ~
cd ~

# Unzip the package
unzip whatsapp_ai_agent.zip
cd whatsapp_ai_agent

Step 3: Run the One-Click Automated Setup

Inside the whatsapp_ai_agent folder, run:

bash setup_termux_env.sh

What this single command does automatically:

  1. Installs all required packages (python, android-tools for ADB, termux-api, ffmpeg).
  2. Installs and automatically activates ADBKeyboard.apk on the phone.
  3. Configures background execution and wake-locks so Android doesn't kill the agent.
  4. Installs all 7 CLI commands (start-ai-whatsapp, check-ai-whatsapp, etc.) directly into $PREFIX/bin so you can run them from anywhere.
  5. Securely prompts for your Google Gemini API Key and saves it with chmod 600.

🔌 Phase 4: Connecting ADB on the Device

Depending on how you connect:

Option A: Via USB Cable (Plugged into PC or USB-OTG) — Easiest

  1. Plug the USB cable in.
  2. A popup will ask "Allow USB Debugging?" on your phone screen. Check Always allow and tap OK.
  3. The agent will automatically detect and prioritize USB Debugging.

Option B: Wireless Debugging (Directly on Phone Without Any Cable)

  1. In phone Settings > Developer Options > Wireless Debugging:
  • Turn ON Wireless Debugging.
  • Tap Pair device with pairing code. Note the Wi-Fi pairing code, IP address, and Port.
  1. In Termux, type:
    adb pair 127.0.0.1:<PAIRING_PORT>
    # Enter the 6-digit pairing code when prompted
  2. Once paired, look at the main Wireless Debugging screen for the active port and run:
    adb connect 127.0.0.1:<ACTIVE_PORT>

🚀 Phase 5: Verification & Daily Usage

1. Test All Connections

Run the built-in diagnostic tool:

check-ai-whatsapp

It will verify ADB, screen status, ADBKeyboard, WhatsApp UI, and Gemini API authentication.

2. Start the Agent

start-ai-whatsapp

The agent starts running in the background and begins monitoring for unread WhatsApp messages!

🎮 Command Cheat Sheet

You can run these commands at any time from any directory in Termux:

Command

What it does

check-ai-whatsapp

Diagnoses connection, battery, keyboard, and Gemini quota.

start-ai-whatsapp

Starts the AI auto-reply agent daemon in the background.

minimize-ai-whatsapp

Enters silent background mode (replies without popping up WhatsApp).

pause-ai-whatsapp

Temporarily pauses replying without stopping the process.

resume-ai-whatsapp

Resumes replying after being paused.

logout-ai-whatsapp

Deletes your stored Gemini API key and lets you enter a new one.

stop-ai-whatsapp

Safely shuts down the agent daemon.

🛠 Helpful Tips

  • To view live agent logs in Termux:
    tail -f /tmp/whatsapp_ai_agent.log
  • Keep Termux Alive: Keep the notification "Termux: Wake lock acquired" visible in your notification bar so Android's battery saver doesn't pause the CPU.
